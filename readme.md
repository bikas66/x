# Basic C Programming Repository

This repository contains basic C programming examples. The programs in this repo demonstrate fundamental concepts in C, such as variables, loops, conditionals, and functions.

## Contents

- **`program1.c`**: A simple "Hello, World!" program.
- **`program2.c`**: A program that demonstrates basic user input and output.
- **`program3.c`**: An example of using loops and conditionals.
- **`program4.c`**: A program demonstrating functions in C.

## Requirements

To compile and run the C programs, you need:

- A C compiler (e.g., GCC).
- A Unix-based or Windows environment with a terminal or command prompt.
